# Texte verständlicher machen

- Verwende aktive Sätze und nenne das konkrete Ziel einer Anweisung.
- Trenne Voraussetzungen, Schritte und das erwartete Ergebnis.
- Ersetze unklare Verweise durch konkrete Dateinamen oder Abschnitte.
