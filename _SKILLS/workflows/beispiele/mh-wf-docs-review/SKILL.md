# Dokumentation prüfen

1. Kläre, welche Dokumentation geprüft werden soll und für wen sie geschrieben ist.
2. Prüfe Lesbarkeit und fehlende Voraussetzungen mit `mh-docs-checklist`.
3. Gib die wichtigsten Befunde mit Fundstelle und Änderungsvorschlag zurück. Ändere Dateien nur auf ausdrücklichen Wunsch.
